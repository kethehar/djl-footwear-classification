SoleAI

KI-gestützte Schuh­klassifizierung mit Deep Java Library (DJL) – entwickelt als Demo-Anwendung für maschinelles Lernen in Java.

DJL Spring Boot ResNet Java 17

Wie es funktioniert

  1. 01
    Bild hochladen

    Ziehe ein PNG- oder JPEG-Bild eines Schuhs in das Upload-Feld.

  2. 02
    KI-Verarbeitung

    Das Bild wird an ein vortrainiertes neuronales Netz (DJL) gesendet.

  3. 03
    Ergebnisse anzeigen

    Die Top-Kategorie sowie alle weiteren Klassen mit Konfidenz werden angezeigt.
